# NEI 双主题系统 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用 CSS 变量驱动的 NEI 双主题系统替换 Workbench 的 slate 暗色硬编码，实现亮色/暗色全局切换，与 Embed 端 NEI 风格统一。

**Architecture:** 扩展 `nei-tokens.css` 为双主题（`:root` 亮色 + `[data-nei-theme="dark"]` 暗色），新增 `useNeiTheme` composable 管理 `<html data-nei-theme>` 属性 + localStorage 持久化。所有 Workbench 组件的硬编码颜色值替换为 `var(--nei-xxx)` 引用。

**Tech Stack:** Vue 3 + TypeScript + CSS Custom Properties，纯 CSS 方案无第三方依赖。

**Verification:** 本项目无自动化 UI 测试，验证方式为 `npm run dev` 启动工作台，肉眼确认亮色/暗色切换正常 + 5 个编辑器 + 全局 chrome 颜色正确。

### Task 1: 创建 `useNeiTheme` composable

**Files:**
- Create: `src/workbench/composables/useNeiTheme.ts`

- [ ] **Step 1: 写入 composable**

```ts
import { ref, watch } from 'vue'

export type NeiTheme = 'light' | 'dark'

const STORAGE_KEY = 'nei-theme'
const ATTR = 'data-nei-theme'

function readStored(): NeiTheme {
  try {
    const v = localStorage.getItem(STORAGE_KEY)
    if (v === 'light' || v === 'dark') return v
  } catch { /* noop */ }
  return 'dark'
}

function applyTheme(t: NeiTheme): void {
  document.documentElement.setAttribute(ATTR, t)
}

const theme = ref<NeiTheme>(readStored())

// 初始应用
applyTheme(theme.value)

watch(theme, (t) => {
  applyTheme(t)
  try { localStorage.setItem(STORAGE_KEY, t) } catch { /* noop */ }
})

export function useNeiTheme() {
  function toggleTheme(): void {
    theme.value = theme.value === 'dark' ? 'light' : 'dark'
  }

  return { theme, toggleTheme }
}
```
